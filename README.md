Project description.

Problem: Traders needed fast, plain-language market insights combining real-time data and AI summarization without heavy dashboards.

Solution: Built a natural-language AI research tool that queries live market data, runs sentiment/metrics analysis, and returns concise, actionable answers.

Tech: Next.js frontend, Framer motion, Tailwind CSS.

Impact: Speeds research workflows, surfaces signals users would otherwise miss, and provides a shareable demo for investors/users.
